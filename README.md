# Qiushuo Ding — Academic Homepage

This repository contains the source code for my personal academic website:

**[https://qiushuoding.github.io](https://qiushuoding.github.io)**

## About

I am a Ph.D. candidate in Economics at the Center for Economic Research, Shandong University. My research interests include:

- Information frictions
- Macroeconomics
- Monetary economics and policy
- Financial markets

The website presents my academic profile, research, publications, conference presentations, and teaching experience.

## Technology

The site is intentionally lightweight and uses:

- Semantic HTML
- Custom CSS with a responsive layout
- Vanilla JavaScript for the interactive abstract display
- Google Fonts
- GitHub Pages for hosting

No build tools or external JavaScript frameworks are required.

## Local Preview

Clone the repository and open `index.html` directly in a browser:

```bash
git clone https://github.com/qiushuoding/qiushuoding.github.io.git
cd qiushuoding.github.io
open index.html
```

Alternatively, serve the directory locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Updating the Site

Most content can be maintained directly in `index.html`, including:

- Biography and contact information
- Research interests
- Publications and paper links
- Conference presentations
- Teaching experience

Changes pushed to the `main` branch are published through GitHub Pages.
